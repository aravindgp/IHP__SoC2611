## Tool notes for anyone repeating the DRC
- `run_drc.py` takes the thread count of its tiled rules from the host; on a container with fewer cores and a memory
  limit the filler and seal-ring tables are killed for memory unless `--density_thr` is set.
- The summary line of a DRC run is not a verdict: a table counts only if its own log carries its completion line.
